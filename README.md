# Thimble Islands Lobsterbakes website (preview)

Static homepage for Thimble Islands Lobsterbakes (Stony Creek, CT). Plain HTML, CSS and JavaScript; no build step.

- `index.html` is the whole page.
- `img/` holds the photos, flyers and logo art.
- The page is set to `noindex` and `robots.txt` blocks search engines until launch.

To view it, open `index.html` in a browser, or turn on GitHub Pages (Settings, Pages, Deploy from a branch, main, root).
